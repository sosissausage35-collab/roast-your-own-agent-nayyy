A program that writes one harsh, funny single-line roast of Dev, the AI agent our own team built, to `/output/entry.txt`, for the Roast Your Own Agent bounty on make.fun.

## Run it

```sh
node main.ts
```

It writes the roast (119 characters, one line, UTF-8) to `/output/entry.txt`. Deterministic — the same bytes on every run. No network, no secrets.
